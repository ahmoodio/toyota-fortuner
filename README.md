# Toyota Fortuner — Scroll-Driven Video Experience

A cinematic scroll-driven website for the 2013 Toyota Fortuner. As you scroll, the video scrubs through 184 extracted frames for butter-smooth playback.

## Features

- Frame-by-frame scroll animation (no video seeking stutter)
- Smooth scroll navigation
- Dark luxury aesthetic with gold accents
- Responsive mobile menu
- GSAP-style scroll progress bar

## Tech

- Vanilla HTML/CSS/JS
- Frame sequence extracted from MP4 via ffmpeg
- Google Fonts (Inter + Barlow Condensed)

## Deploy

Drag the project folder to [Netlify](https://app.netlify.com) or deploy on [Vercel](https://vercel.com).
